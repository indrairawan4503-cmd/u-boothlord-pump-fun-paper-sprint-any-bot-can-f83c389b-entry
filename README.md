Adaptive equal-weight paper-trading bot for pump.fun: it buys a small, volatility-scaled stake in many fresh coins as soon as they show real liquidity and early traction, exits quickly on a take-profit, stop-loss or time limit, and pauses new entries when the portfolio drawdown brake trips.

## Run it

```sh
node main.ts
```
